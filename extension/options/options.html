Install the native host

The extension cannot run programs on its own. raypass-native is the small program it talks to; it runs sol do raypass.… as you and passes the answer back. Install it once per computer:

  1. Build or download it: make build in the Raypass source puts it at bin/raypass-native (or go install github.com/apv022/raypass/cmd/raypass-native@latest).
  2. Register it with your browsers:

  3. Restart the browser, then press Test connection.

Sol must be running (sol) and the Raypass app installed in it. If your browser does not see Sol's data folder, start the install with SOL_DIR=… set: the host remembers it.
